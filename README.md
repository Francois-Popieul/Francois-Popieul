# 👋 Hi, I'm François Popieul

### 🎮 Video Game Localization Specialist & Application Developer

For over 24 years, I have worked in video game localization, combining linguistic expertise with a passion for technology.

My journey into software development began while automating repetitive translation tasks. What started with custom AutoHotkey tools gradually evolved into learning C# and building applications that improved workflows for both myself and fellow translators.

Today, I bring together deep domain knowledge, analytical thinking, and software development skills to create practical solutions to real-world problems.
